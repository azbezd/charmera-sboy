# Участие в СБОЕ

## Ошибки и аппаратные варианты

Создайте [Issue](https://github.com/azbezd/charmera-sboy/issues) с описанием результата и того, что ожидали. Для аппаратных вопросов укажите USB VID/PID, размер и SHA-256 дампа, версию прошивки, родной или заменённый экран. Цвет корпуса полезен как описание экземпляра, но не как идентификатор совместимости.

Не прикладывайте личные снимки, пароли, полные RAM-дампы или закрытую заводскую прошивку. Для демонстрации проблемы используйте специально снятую неперсональную сцену. Новые профили требуют анализа адресов и отдельных проверок: отключать guard ради похожего устройства нельзя.

## Проверки без камеры

```sh
python3 -m unittest discover -s tests -v
python3 -m unittest discover -s tools -p 'test_*.py' -v
```

Эти проверки входят в GitHub Actions и не требуют заводского бинарника.

После [локального восстановления этапов](docs/getting-started.md) из собственного совместимого дампа:

```sh
python3 -m pip install -r requirements-dev.txt
python3 -m unittest discover -s custom-firmware/tools -p 'test_*.py' -v
```

Эмулятор проверяет пиксели, границы памяти, ABI, меню и последовательность обработки видео. Он не измеряет аппаратный FPS, цветопередачу LCD или синхронизацию звука.

## Изменения прошивки

`custom-firmware/tools/` содержит собственный OR1K-ассемблер, ядра, генераторы меню и исторические сборщики. `patches/` хранит изменённые байты этапов; основной сборщик проверяет полный входной и выходной хеш каждого этапа. Подробности — в [архитектуре](docs/architecture.md).

Для нового выпуска нужны уникальный update ID, подтверждённые границы изменений, тесты затронутого поведения и явно описанный статус аппаратной проверки. Сохраняйте заводскую резервную копию. Не переносите полный образ между вариантами камер.

## Документация и оформление

README — короткий вход для владельца камеры; подробные адреса, методы и протоколы находятся в `docs/`. Русский язык, отсутствие эмодзи, читаемые изображения на светлой и тёмной теме, минимум бейджей. Проверяйте локальные ссылки и фактические команды. Ограничения совместимости должны быть видны до установки.

Обложка и демонстрация эффектов описаны в [visuals.md](docs/visuals.md). Для текстовых представлений сохранён [ASCII-знак](docs/ascii-wordmark.md). Не публикуйте личные снимки из исследовательского архива.
