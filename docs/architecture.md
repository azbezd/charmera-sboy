# Устройство модификации

Это патчи закрытой заводской прошивки, а не полная реализация камеры с нуля. Сенсор, JPEG-кодировщик, файловая система, питание и USB в основном остаются штатными.

```text
sensor -> YUV frame -> selected software effect -> date stamp -> JPEG
                         |                                |
                         +--> LCD preview                 +--> photo / AVI
                               + transient menu                + native audio
```

## Код и память A

OR1K, little-endian, наблюдаемая сборка без delay slots. Для основной программы `file_offset = RAM_address - 0x02000000 + 0x2400`. Начальные 0x2400 байт образа сохранены. Новые ядра размещены в областях заменённых штатных эффектов, с проверкой границ и ABI.

| Область | Назначение |
|---|---|
| `0x02049964` | Штатный setter эффекта, ограниченный hook выбора пользовательских режимов |
| `0x02018088` | Штатный диспетчер YUV-эффектов |
| `0x0205195c` | Ядро сортировки |
| `0x02051b20` | Worker для обработки кадра видео вне IRQ |
| `0x020520a8` | Маршрутизация пар I/II |
| `0x02052120` | Новые ядра, включая VHS |
| `0x02052480` | Усиление яркостного контраста для II |
| `0x02052600` | Меню предпросмотра |
| `0x02052700..0x02053000` | 12 растровых подписей |
| `0x02053000` | Вызов парсера TIME после обновлятора |
| `0x0208a35c` | Штатный миллисекундный tick, источник таймера меню/фазы VHS |

## Эффекты

- **VHS:** смягчение яркости, приподнятый чёрный, периодические строки развёртки, движущиеся полосы tracking и задержанная/пониженная цветность. Это стилизация; не физическая эмуляция видеомагнитофона.
- **ЧЕРНИЛА:** художественное упрощение/постеризация.
- **СОРТ:** стабильная сортировка 2×2 YUV-блоков по яркости в ограниченных окнах и диапазонах. Размер окна зависит от размера кадра; предпросмотр и большое фото поэтому различаются.
- **ПРИЗРАК:** смещения/смешения изображения.
- **РАЗРЫВ:** полосовые смещения.
- **РАСТР:** упорядоченный растр.

Вариант II добавляет яркостный контраст, но не новый алгоритм. Пары идут подряд, VHS стоит первым. Временное меню рисуется только для наблюдаемого 160×80 предпросмотра, вне нижней даты. На больших сохранённых кадрах меню отсутствует.

## Видео

В 0.4 включён существующий путь обработки из RAM. Обработчик CSI приостанавливает захват и отмечает готовность; основной цикл выполняет эффект, затем штатную дату, JPEG и AV writer. Пиксельные циклы не выполняются в IRQ. Штатный звуковой writer сохранён. В настоящем ролике 0.4 проверены эффекты и наличие PCM mono 16 kHz; точная синхронизация и FPS не измерялись.

## Графика и подсветка

JPEG-ресурсы включения/выключения/USB заменяются внутри прежних allocations, без перемещения таблицы ресурсов. Иконки — 16×16 палитровые маски. В 0.9 возвращены ресурсы 20/21: выключенный/включённый свет. Весь исполняемый код 0.9 идентичен 0.8, поэтому фото/видео и аппаратная логика света не менялись этим выпуском.

## Воспроизводимость

Основной `tools/build.py` последовательно накладывает только изменённые байты из `patches/sboy-0.9.json`. На каждом этапе проверяет полный входной и выходной SHA-256, границы/порядок диапазонов и пути вывода. Неизвестный исходник отклоняется до записи файлов. В bundle нет полного заводского образа.

Исторические `build_*.py` сохранены для изучения и доработки, а не как отдельный универсальный установщик. Они ожидают предыдущие локальные этапы. Генерация JPEG исходниками может зависеть от версии Pillow/libjpeg; точное воспроизведение опубликованного образа выполняется патч-пакетом. Для новых сборок нужны обновлённые тесты, новый update ID и проверка на устройстве.
