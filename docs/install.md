# Установка и проверка

Этот путь применим только после совпадения заводского SHA-256 A и подтверждения заменённого ST7735. Сначала сохраните два совпавших заводских дампа на компьютере и отдельную копию. Файл RAM/ROM snapshot не является SPI-прошивкой.

## Положить файл на карту

1. Соберите образ по README. Проверьте полный SHA-256.
2. Завершите USB-ридер, переподключите кабель при необходимости и дождитесь карты в Finder. Камера A автоматически переходит в накопитель; выбирать MEMORY в ней не нужно.
3. Скопируйте `custom-firmware/builds/sboy-0.9/DestBin.bin` в корень **карты камеры** под точным именем `DestBin.bin`. Если там уже есть неизвестный файл с этим именем, сначала сохраните и определите его, не заменяйте вслепую.
4. Сравните исходный и скопированный файл, например `shasum -a 256` для обоих путей. Ожидаемый хеш:

```text
3c67c73acb5d34c85da6bd28c6edfef9179c0884505eabe53e99089624cea010
```

5. Завершите запись ОС и размонтируйте карту через Finder или `diskutil unmountDisk diskN` с ранее проверенным номером. Не вынимайте саму microSD и не отключайте питание.
6. Выключите и включите камеру кнопкой. Штатный загрузочный сценарий обнаружит файл. Оставьте питание стабильным, не нажимайте кнопки и не отсоединяйте кабель две минуты. После обновления камера может выключиться — включите её снова.

Обновлятор **стирает SPI-флеш целиком** перед записью. Отключение питания в этот момент может лишить камеру рабочего USB-режима. Этот проект не содержит универсального USB-unbrick.

## Проверить результат

1. Подключите USB и повторите `tools/backup.py` с актуальным проверенным номером диска.
2. Оба новых полных чтения должны совпасть друг с другом **и с установленным образом** по SHA-256. Появление заставки само по себе недостаточно для проверки всех байтов.
3. После возврата накопителя удалите с карты только известный файл обновления, сохранив локальные копии. Это исключит его повторную установку после других версий.
4. Отключите USB. Проверьте фото, видео со звуком, сохранённые файлы на компьютере, предпросмотр, ориентацию/цвета, переключение эффектов и скрытие меню.
5. Удержание ↓ должно включать/выключать постоянный белый свет; в 0.9 должен меняться значок молнии. Логика та же, что в заводской прошивке.

## Часы

После 0.5 вызывается существующий парсер `TIME.txt`. Формат — ровно 21 ASCII-байт:

```text
2026-10-13 12:34:56 Y
```

Это пример формата, **не текущее время**. Используйте свои местные дату/время непосредственно перед перезапуском; строка не содержит часовой пояс и отстаёт на время между подготовкой и загрузкой. Заводской код имел этот парсер, но не вызывал его при старте. Физическое подтверждение точности RTC после нашей правки пока не записано. Сохранённые медиа отображают только дату; часы RTC не удалены.

## Возврат версии

Штатный обновлятор сравнивает build time/date с текущим образом и пропускает одинаковый идентификатор. В цепочке релизов каждому образу назначен отличный идентификатор.

При работающей камере можно установить ранее сохранённую совместимую сборку тем же SD-способом. Для нашего заменённого экрана прежняя проверенная 0.4 сохраняется среди локально восстановленных этапов. Заводской дамп вернёт также **заводскую LCD-таблицу**, поэтому с заменённым экраном изображение снова может исчезнуть. Не используйте дамп камеры B как восстановление A.

Если камера не загружается и не предоставляет рабочий USB-накопитель, этот путь недоступен. Тогда требуется отдельное исследование аппаратного восстановления; инструкции с угадыванием напряжения, прищепки или случайными loader-командами здесь не приводятся.
