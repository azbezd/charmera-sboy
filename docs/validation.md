# Проверки и границы выводов

Состояние на 2026-10-13. «Файл на карте», «владелец увидел результат» и «весь SPI прочитан обратно» — разные уровни подтверждения.

| Возможность | Свидетельство |
|---|---|
| USB-чтение SPI A и B | Два полных одинаковых чтения каждого образца; разные SHA-256 |
| Новый ST7735, ручное рисование | RAM-тест: владелец подтвердил отдельные цветные полосы; полный SPI до/после не изменился |
| Штатный UI на ST7735 | Владелец видел USB/меню; затем постоянная установка и работа камеры |
| Геометрия и инверсия ST7735 | Исправлены по наблюдениям владельца; он подтвердил работающий экран |
| RGB/BGR-правка 0.7 | Исходные JPEG на компьютере имели правильные цвета, LCD — неверные; MADCTL изменён. Отдельного финального подтверждения одинакового фото после правки нет |
| Эффекты сохранённых фото | Реальные JPEG 0.2/0.3 исследованы локально, без публикации личных снимков |
| Эффекты видео и дата без времени | Реальный AVI 0.4 содержит эффекты и дату; PCM-аудиотрек присутствует |
| Точный FPS / аудиосинхронизация | Не измерены, повышение не обещано |
| Последний полный SPI readback установленной версии | 0.4: `43f28bbcd158cead7a239213b6b14a03f48256e5631f4582ca36847725e1ded3` |
| Меню и новые варианты после 0.4 | Эмуляторные проверки и частичные наблюдения UI; не все режимы оценены на устройстве |
| 0.8 VHS/попарный порядок | 42 offline-теста прошли; художественная оценка VHS на устройстве отдельно не зафиксирована |
| Белая подсветка | Владелец подтвердил включение при удержании ↓ |
| 0.9 значки и штатная логика света | Владелец подтвердил успешную установку, свет и смену значка; полный SPI 0.9 после установки пока не прочитан |
| RTC после TIME.txt | Механизм вызова исправлен; фактическая точность пока не проверена |

Публичный комплект воспроизвёл 0.8 из заводского дампа с точным SHA-256; 42 проверки эффектов прошли заново уже в изолированном дереве проекта. 0.9 сохраняет весь исполняемый код 0.8. Проверки публичного сборщика отдельно покрывают неверный исходник, повреждённые патчи, выход за границы, перекрытия, выход пути за папку сборки и цепочку хешей.

Offline-тесты не заменяют наблюдение белого светодиода, цветопередачи LCD, видео и стабильности питания на конкретной плате. CI работает без камеры и без заводского бинарника; полный набор эмуляторных тестов запускается локально после восстановления этапов из собственного совместимого дампа.
