# Красная камера B: проверенная исходная прошивка

Статус на 13 октября 2026: чтение конкретного экземпляра подтверждено, кастомная прошивка для него пока не собрана. Готовые патчи жёлтой камеры A к нему не применяются.

## Проверка после использования общей карты

После удаления файла обновления с общей microSD прошивка красной камеры была прочитана через USB дважды. Оба образа размером 1 048 576 байт полностью совпали с её исходным дампом: **0 изменённых байт**. Прошивка жёлтой камеры не установилась. Команд стирания или записи flash при проверке не отправляли.

```text
SHA-256  3a6fa4735a7bb5a6f302a011ca8332d11121d64a930404533eedd59cb3eb6c2b
USB      05e3:f12b
SCSI     Buildwin / Media-Player / 1.00
LCD      jd9850_spi, 80 x 160
```

Активная таблица LCD в RAM совпала с заводской таблицей во flash. Сохранены два SPI-образа, RAM, повторное чтение области кода, два чтения окна ROM и таблица SDK. Проверенный диапазон SPI — `0..0xfffff`; это не независимое измерение физической ёмкости микросхемы.

В прошивке присутствуют строки `AX3295B-V2.1` и `20260704-V3.0`. Это разные программные идентификаторы; маркировку физической платы и модель сенсора по ним не устанавливаем.

## Отличия, важные для переноса

| Объект | Красная B |
|---|---|
| Каталог ресурсов, смещение в файле | `0x7f800` |
| Заставка включения, ресурс 11 | `0x9a20d`, 3705 байт |
| Заставка выключения, ресурс 12 | `0x9b086`, 2209 байт |
| Идентификатор обновления, ресурс 15 | `0xbde9d`, `AX3295B-V2.1` |
| Экран USB, ресурс 16 | `0xbdea9`, 2324 байта |
| Таблица LCD во flash | `0x78e84`, 1008 байт |
| Активная таблица LCD в RAM | `0x02096600` |

Ресурсы имеют другие размеры и смещения. Настройки ST7735 из сборки A предназначены для заменённого дисплея и не нужны штатному экрану B. Алгоритмы эффектов можно адаптировать, но места вызовов, буферы, обработчики клавиш и путь записи видео требуют отдельного разбора.

## Обновление с карты

В исследованном коде обновления B используется то же имя `DestBin.bin`, но другая проверка версии: сравнивается ресурс 15 с данными файла по соответствующему смещению. Равная версия пропускает обновление. Схему с изменением времени сборки A переносить сюда нельзя.

В просмотренном пути перед стиранием flash не найдено отдельной проверки совместимости платы. Это результат статического разбора, а не испытание неправильной прошивки; все вспомогательные функции и альтернативные пути не проверены исчерпывающе. Отсутствие случайного обновления в этом сеансе не доказывает защиту от чужого образа.

**Не переставляйте карту с `DestBin.bin` между камерами.** Храните образы на компьютере и кладите обновление на карту только для конкретного подтверждённого экземпляра.

Сборщик проекта по-прежнему отклоняет заводской образ B. Публичный USB-сценарий резервного копирования пока поддерживает A; эта проверка B выполнена отдельным исследовательским инструментом с проверками машинного кода. `tools/identify.py` распознаёт сохранённый дамп B и показывает его собственный идентификатор, не читая метаданные по адресам A.
